# How the Source tables become the blob sections apo reads.  One section per line:
#   SECTION  FILE  COLUMN  MODE  [OPTIONS]
# Modes: each (one number per record), text (one string per record), flat (the records' lists in order), start (the 1-based start of each record's
# list in flat), count (each record's list length), group_start / group_count (per key 1..K of COLUMN: the 1-based
# first record and the number of records), records (the number of records), derived (a section apo builds at startup
# from the others: only its BYU name is recorded here).
# Options: pad=W (each list padded with 0 to W), total=N (the whole section padded with 0 to N), div=W (counts and
# starts in units of W items), zero_empty (start 0 for an empty list), sentinel (one more start after the last),
# keys=K, first=N (only the first N records), lead=N (N zeros before the first list, counted by start), byu=NAME
# (the section's name in the BYU tables).
